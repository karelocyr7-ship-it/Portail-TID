# Rapport de tâche

## Résumé

Audit initial strictement en lecture seule et préparation locale de la
configuration de l’orchestrateur multi-applications.

## Applications

TDB, CASH-RECON, ATF, Revue-PDV, GParc, MDM et Recrutement OM & Telco.

## Commandes et contrôles

| Contrôle | Résultat |
|---|---|
| `git status --short --branch` sur les dépôts confirmés | exécuté, sans modification |
| lecture des remotes et branches | exécutée sans secret |
| `docker ps` / ports / timers systemd | exécutés en lecture seule |
| recherche de `.env` | présence signalée sans lecture de contenu |
| services, tests et builds déclarés | inventoriés depuis les manifestes |

## Résultats

- Trois VM applicatives sont accessibles avec des preuves suffisantes.
- Les agents GParc existent déjà ; les autres agents applicatifs restent à
  configurer et leur installation n’a pas été tentée.
- ATF reste `to_confirm`.
- Les dépôts TDB, CASH-RECON, Revue-PDV et Recrutement comportent des états
  locaux non propres ; aucun agent ne doit les réinitialiser.

## Modifications locales

Les propositions sont dans `orchestration/` et les rapports d’infrastructure
dans `docs/infrastructure/`. La page d’administration des rapports est
déployée sur le Portail et sa migration Prisma a été appliquée après fusion
dans `main`.

## Actions humaines nécessaires

- confirmer le dépôt source MDM ;
- valider les règles d’accès, les agents et la procédure de déploiement ;
- appliquer séparément les migrations du portail avant activation de la page

## Statut

Configuration centrale active ; aucune VM applicative modifiée et aucune tâche
agent exécutée lors de l’activation.
