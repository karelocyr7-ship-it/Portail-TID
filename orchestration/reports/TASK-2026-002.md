vers le compte `tad-agents`.

Installer `bubblewrap` via la procédure système validée, puis relancer les
audits en lecture seule. L’authentification de service est désormais valide.

`.task` dans les files runtime. Une seule tâche est traitée par le dispatcher ;
les cinq autres actions de démonstration restent en attente. Le premier
traitement d’action validée a été lancé sans modification distante. Le
