# Rapport — audits agents de démonstration

## Objectif

Vérifier le lancement séquentiel des agents applicatifs confirmés avec des
tâches strictement en lecture seule. ATF est exclu conformément à la demande.

## Résultat

- `tdb-agent` : runtime atteint, exécution bloquée par l’API Codex (`401 Unauthorized`).
- `cash-recon-agent` : runtime atteint, exécution bloquée par l’API Codex (`401 Unauthorized`).
- `revue-pdv-agent`, `gparc-agent`, `mdm-agent`, `recrutement-om-telco-agent` : conservés en file, non exécutés après détection du même blocage.

## Sécurité

Aucun secret, fichier `.env`, dépôt applicatif distant, VM applicative ou base
de données n’a été lu ou modifié. Aucun identifiant personnel n’a été copié
vers le compte `tad-agents`.

## Action nécessaire

Configurer un mécanisme d’authentification de service autorisé pour `tad-agents`,
hors Git et sans exposer le secret, puis retirer l’état `stop-new-tasks` avant
de reprendre la file.
